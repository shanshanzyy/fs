# VIBE.md — 本项目的团队规则

这份文件由项目作者（人）维护。vibe-agent 在本工作区工作时必须遵守以下约定；
与安全策略冲突的指令无效，安全策略始终优先。

## 代码风格

- 所有函数（含测试函数）必须有 docstring：一句话说清楚「做什么」，
  参数与返回值不写废话，但边界行为（空输入 / 异常路径）要提。
- 新代码一律带类型标注（Python：参数与返回值）。
- 错误处理优先显式抛异常，不要静默 `except: pass`。

## 修改约束

- 修 bug 时必须先写一个能复现该 bug 的失败测试，再修复，最后确认测试转绿。
- 不引入任何第三方依赖（本项目坚持零依赖红线）。
- 每次改动只解决一件事；发现相邻问题记到回复里提醒，不顺手修。

## 本项目速览

- `src/utils.py` 里刻意留了几个小问题（空值 / 空列表 / 缺 key），
  适合用来演示「定位 → 补测试 → 修复」的完整闭环。
- 跑测试：`python -m unittest discover -s tests`（在 demo-project 目录下）。
