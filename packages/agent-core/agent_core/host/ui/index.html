Vibe Coding Agent

本地编码智能体 · 代码不离开这台机器，高危动作必须先经你审批

开始

在右侧对话框描述任务，Agent 会自己读代码、改文件、跑命令。

使用要点

  • 左侧资源管理器可打开文件查看，Markdown 文件支持渲染预览
  • Agent 的每一步都会出现在右侧对话流与底部输出里
  • 底部终端页签是你自己的交互式终端，与 Agent 通道互不干扰
  • 改完的文件在改动面板里审查 diff，可整体回滚
  • 审批弹窗出现时 Agent 会暂停等你决定，Esc 拒绝、Ctrl+Enter 批准
